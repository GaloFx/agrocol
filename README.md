# 🌱 AGROCOL – AgroData Colombia
Sistema de inteligencia de mercados agrícolas de Colombia anclado a datos oficiales **DANE-SIPSA** y **UPRA-EVA**.

## 🚀 Despliegue en Streamlit Community Cloud
1. Sube estos archivos a tu repositorio de **GitHub**.
2. Entra a [Streamlit Cloud](https://share.streamlit.io/).
3. Conecta tu repositorio y selecciona el archivo principal `app.py`.
4. ¡Listo! Tu plataforma quedará proyectada en la web.

## 📂 Estructura del Proyecto
- `app.py`: Código principal adaptado a Streamlit con la pestaña de Configuración/Carga de bases de datos.
- `requirements.txt`: Librerías requeridas para el entorno de producción.
- `README.md`: Documentación y guía de despliegue.
